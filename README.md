# 🎵 ByteBeat

แอปเล่นเพลงจาก YouTube สำหรับ Windows

> repo นี้เก็บเฉพาะไฟล์ติดตั้ง (release) เท่านั้น — ไม่มี source code

## ดาวน์โหลด

ไปที่หน้า **[Releases](../../releases/latest)** แล้วโหลดไฟล์ `ByteBeat-Setup-x.x.x.exe` ตัวล่าสุด

## วิธีติดตั้ง

1. ดับเบิลคลิกไฟล์ `.exe` ที่โหลดมา
2. ถ้าเจอหน้าต่าง **"Windows protected your PC"** (Windows SmartScreen) — เป็นเรื่องปกติ เพราะแอปนี้ยังไม่มี code signing certificate:
   - คลิก **"More info"**
   - คลิก **"Run anyway"**
3. ทำตามขั้นตอนในตัวติดตั้งจนจบ

## อัปเดตเวอร์ชันใหม่

ไม่ต้องมาโหลดไฟล์ใหม่เอง — ตัวแอปเช็คเวอร์ชันใหม่ให้อัตโนมัติทุกครั้งที่เปิด แล้วจะแจ้งเตือนให้กด restart เพื่อติดตั้งเวอร์ชันล่าสุดเอง

## ข้อจำกัดการใช้งาน

แอปนี้สร้างขึ้นเพื่อใช้งานส่วนตัวเท่านั้น (personal use) — สำหรับฟังเพลงจาก YouTube ผ่านสตรีมมิงเป็นหลัก ไม่ได้มีเจตนาให้ใช้ดาวน์โหลดเพลงเพื่อแจกจ่ายต่อ ขาย หรือทำเชิงพาณิชย์ในรูปแบบใด ๆ การใช้งานแอปนี้อาจขัดกับข้อตกลงการใช้งาน (Terms of Service) ของ YouTube — ผู้ใช้เป็นผู้รับผิดชอบการใช้งานของตัวเองแต่เพียงผู้เดียว
